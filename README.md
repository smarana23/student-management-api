// Project Overview

This project is a backend application built using Node.js, Express.js, and MySQL.  
The main idea behind this project is to store school information and help users find nearby schools based on their current location using latitude and longitude coordinates.


// Features

-> Add new school details into the database
-> Avoid duplicate school entries
-> Fetch schools sorted by nearest distance
-> Validate user inputs and coordinates
-> Connect and manage data using MySQL
-> Built using REST API architecture



// Technologies Used

-> Node.js
-> Express.js
-> MySQL
-> MySQL Workbench
-> Postman
-> dotenv
-> cors
